# She Notices
Static V1 for GitHub Pages.

## Publish free on GitHub Pages
1. Create a public repository named `she-notices`.
2. Upload all files/folders from this package, preserving the structure.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. Replace `YOUR-USERNAME` in `robots.txt` and `sitemap.xml` with your GitHub username.
5. After publishing, add the site to Google Search Console and submit `/sitemap.xml`.

## Before launch
- Add Alina's real social/profile links only where you want them.
- Review/edit article wording so it genuinely reflects Alina's own perspective.
- Keep images and external destinations compliant with the platforms/services you use.
